# slm-ja

日本語だけで学習する小さな言語モデル（SLM）。1M・10M・100M パラメータの 3 段階を同じコードで学習しています。Scala 3 で、行列ライブラリを使わず、
ニューロンごとのループで順伝播と逆伝播を手で書いています。依存は Scala 標準ライブラリだけ。

「[行列を使わない Transformer 入門](https://kmizu.github.io/no-matrix-transformer/)」の続きとして、
あちらの 7,000 パラメータのおもちゃを、実際に文章を学べる大きさまで育てたものです。

## モデル

| 項目 | 値 |
|---|---|
| トークン | 文字単位（出現 10 回以上の 3,612 字 + UNK） |
| d_model / heads / layers / FF / context | 128 / 4 / 3 / 512 / 128 |
| 出力ヘッド | 入力埋め込みと共有 |
| パラメータ数 | 1,077,533 |
| 学習 | AdamW（β=0.9, 0.95、重み減衰 0.05）、予熱つき cosine、勾配クリップ 1.0 |

## データ

青空文庫の著作権切れ・新字新仮名の作品を 313 本（約 641 万文字）。`data/fetch.py` が索引を読んで
GitHub ミラーから取得し、ルビ・注記・ヘッダ・底本情報を落として `data/corpus.txt` にまとめます。
末尾 3% を検証用に分けます。

```bash
python3 data/fetch.py 6000000
```

## 使い方

```bash
sbt test                                             # 勾配検査（数値微分と 1e-5 で一致）ほか
sbt "runMain slm.Train steps=3000 batch=32"          # 学習（checkpoints/ja1m に保存）
sbt "runMain slm.Generate prompt=　吾輩は count=200"   # 生成（1 文字ずつの推論。method=recompute で旧方式、time=1 で所要時間）
```

密な層の順伝播と逆伝播は、AVX-512 の CPU では C のカーネル（`native/slmkern.c`、Java の FFM API で呼ぶ）で動きます。結果は Scala のカーネルと bit 単位で同じで、C コンパイラが無い環境や `-Dslm.native=false` では Scala のカーネルで動きます。行列ライブラリは使っていません。

生成は層ごとの状態を持ち回す `Decoder` で行います。線形注意では 1 文字あたりの計算が文脈長に依らず、softmax 注意は KV キャッシュを使います。

長く回すときは sbt を介さず `java -cp` で起動する方が楽です（`sbt "export Runtime/fullClasspath"`）。

## 実装

- `Model.scala` — パラメータは 1 本の配列。`Layout` が各部品の区間を持つ。`forward` / `backward` は
  ニューロンごとの while ループ。注意は「各位置 i について j ≤ i と内積 → softmax → v を混ぜる」をそのまま書く。
- `Optimizer.scala` — AdamW、勾配クリップ、学習率スケジュール。
- `Train.scala` — 系列ごとに並列（スレッドごとに勾配バッファを持ち、最後に足す）。
- `GradientCheckTest.scala` — 小さい設定で全種類のパラメータについて数値微分と突き合わせる。

## 高速化の記録（行列ライブラリは使わない）

`slm.Bench`（本番と同じ大きさで `lossAndGrad` を 32 系列）で測った値。

| 手 | 1 スレッド | 16 スレッド | 何が効いたか |
|---|---:|---:|---|
| 最初の版（トークンごとに全部品を回す） | 650 | 1,430 | – |
| 内積を 4 本のアキュムレータに分ける + 作業領域の使い回し | 740 | 1,430 | 単スレッドは少し速い。並列が伸びないのはメモリ帯域の上限（トークンごとに 8.6MB の重みと勾配を読み書き） |
| **ループの入れ替え**（ニューロン外側・トークン内側。重み 1 行を L1 に置いたまま全トークンに使う） | 810 | **5,350** | 重みの読み出しが系列あたり 1 回になり、メモリ律速が外れて並列が 6.6 倍伸びる |
| **SIMD**（JDK Vector API、AVX-512 で 8 個の数を同時に。内積と `y += α·x`） | 2,060 | **11,250** | 計算そのものが 2.5 倍 |
| **Float32 化 ＋ レジスタブロッキング**（重み 1 行の読み込みをトークン 4 本で共有。SIMD は 16 レーンに） | 4,200 | **27,700** | 帯域半分・レーン倍 |
| 順伝播 4 トークン × 2 ニューロン、逆伝播の dx をニューロン 4 本まとめ | 4,580 | **28,000** | 1M では頭打ち。10M 設定では 2,700 → 3,100 |

通算 19 倍（1M 設定）。10M 設定（d=256、12 層、文脈 256）では 3,100 tok/s、約 200 GFLOPS。
Float32 版の勾配は Double の参照実装（`src/test/scala/slm/reference/`、数値微分で検証済み）と相対誤差 1e-4 で一致することをテストしている。どれも「行列」ではなく、キャッシュを意識したループ順序と、1 命令で複数の数を扱う命令の話。
JDK 25 で `--add-modules=jdk.incubator.vector` が要る（sbt の run / test には設定済み）。

## 結果（2026-09-24、3,000 ステップ = 約 1,230 万トークン、2 時間 26 分）

検証損失（末尾 3%、64 窓の平均、1 文字あたりの nat）:

| ステップ | 200 | 600 | 1000 | 1400 | 2000 | 2600 | 3000 |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 検証損失 | 4.08 | 3.52 | 3.22 | 3.11 | 2.94 | 2.88 | **2.85** |

当てずっぽうは log 3613 = 8.19。最終 2.85 nat = 4.11 bit/文字（文字あたりパープレキシティ 17.3）。

生成例（温度 0.7、上位 40 字から抽選、乱数種 3）:

```text
　私はその時、また、何かに何か、僕の目後の口を、あわしの顔をおかえ、あわないことをいうのである。
　そして、わしは、そのことばかりである。
　私は、あの人の目が、自由にあたるような気がした。
```

```text
「おい、まだ、わたしをおわざわす時は。」
　と、いつもやに、ふたりも、おどろく、そのときは、またおれいさんのおりに、いいとおっしゃって、
```

助詞・句読点・鉤括弧・字下げは正しく、文の形はできています。意味は通りません。1M パラメータ・
1,200 万トークンの文字単位モデルとしては、おおむね期待どおりの水準です。

学習済みモデルは `checkpoints/ja1m/`（`params.bin` 8.6 MB、`vocab.txt`、`config.txt`）。

## 100M パラメータ版（2026-09-26）

102,607,398 パラメータ（d=768、12 ヘッド、14 層、FF 3072、文脈 256、線形注意）を、10M と同じコーパス・語彙で 4,096 updates（33.5M トークン）学習した。
CPU 1 台（Ryzen 7 8700G、8 workers）で 26.6 時間、平均 343 tok/s。詳細と実測は [docs/100m-run.md](docs/100m-run.md)。

| モデル | 消費トークン | quick64 | final1024 |
|---|---:|---:|---:|
| 10M（softmax 注意） | 33.5M | 2.880 | 2.872 |
| **100M（線形注意）** | 33.5M | 2.838 | **2.831** |

同じトークン数で、100M が 10M を 0.042 nat/文字下回った（同じ評価窓 `even64-v1` / `even1024-v1`）。

```text
「おい、どこで」
　と、いつか、小腰に、それを、どうかすると、小袖の柄になって、
「いや、そんなものではない」
　と、小次郎は、ひとりで、
「小次郎どの」
　と、いった。
```

2026-09-26 に、学習データの 1 エポック（8,410 updates）までの warm restart の延長を step 4,525 まで進めて止めた（`extendTo=`、詳細は docs）。
次の本番は、位置埋め込みなし（`positions=none`、生成で窓を詰め直さずに状態を持ち回せる）で最初から 1 エポックを組み、別の PC で回す予定。
生成は 1 文字ずつの推論に切り替えて、100M で 1 文字あたり約 7 倍速くなった。

重み（1 世代 1.15 GiB）はリポジトリに含めていない。下のコマンドで同じ run を再現できる。学習基盤の中身は次のとおり。

- 線形注意（`attention=linear`、ヘッドごとの減衰つき、系列長に対して O(n)）を追加。既存の softmax 注意も残っている
- full-state checkpoint（params / Adam m,v / step / 乱数の規約 / schedule / データの hash）を世代ごとに保存・検証し、`scripts/resume-100m.sh` で続きから再開
- 評価は forward のみ、勾配集約と AdamW はパラメータ区間で並列、固定 worker pool
- Preflight（`mode=preflight`）で形状・メモリ・データを配列確保の前に確認

```bash
SLM_HEAP=12g scripts/run-100m.sh corpus=data/corpus.txt vocabFile=checkpoints/ja10m/vocab.txt \
  d=768 heads=12 layers=14 ff=3072 context=256 attention=linear batch=32 threads=8 steps=4096 \
  lr=3e-4 warmup=256 wd=0.1 seed=0 evalEvery=250 saveEvery=250 saveSeconds=600 sampleEvery=0 \
  stopFile=runs/ja100m/STOP out=runs/ja100m
```

## 10M パラメータ版（2026-09-25）

| 項目 | 値 |
|---|---|
| データ | 青空文庫 3,911 作品・7,100 万文字（`python3 data/fetch.py 80000000 --all`） |
| トークン | 文字単位（出現 50 回以上の 4,133 字 + UNK） |
| d_model / heads / layers / FF / context | 256 / 8 / 12 / 1024 / 256 |
| パラメータ数 | 10,605,606 |
| 学習 | 4,000 ステップ × 8,192 トークン ≈ 3,300 万トークン（0.5 エポック）、lr 6e-4、wd 0.1、2 時間 50 分（約 3,050 tok/s） |

```bash
sbt "runMain slm.Train corpus=data/corpus.txt steps=4000 batch=32 lr=6e-4 warmup=200 wd=0.1 minCount=50 d=256 heads=8 layers=12 context=256 ff=1024 out=checkpoints/ja10m"
```

検証損失（末尾 3%、64 窓の平均）:

| ステップ | 250 | 500 | 1000 | 2000 | 3000 | 4000 |
|---:|---:|---:|---:|---:|---:|---:|
| 検証損失 | 4.10 | 3.54 | 3.13 | 2.89 | 2.76 | **2.70** |

1M 版（2.71）と数字は近いが、コーパスが違うので直接は比べられない（こちらは 11 倍大きく多様なコーパスの 0.5 エポック）。
4,000 ステップ時点でまだ下がっていて、`resume=checkpoints/ja10m/last` で続きを回せる。

生成例（温度 0.7、上位 40 字から抽選）:

```text
　私はその時、自分はまたなにか考えていた。その時も、二人とも彼女の手に引き寄せて、すぐにいった。
「もう何です。」と私は考えた。
　その時、私は言った。「何でもないわ。」と私は尋ねた。
```

```text
「おい、どうも、それから、まだ、今日までになって、どうしても、どうやら、おっしゃらないのか。」
　と、いいました。
「あれは、こんなようなことをしたのか？　それは、そのおどろきがあろうと思うのか。」
　と、おじいさんが、いいました。
```

```text
　夜になると、大川は、やがて、そこに立った。
　その時、正吉は、小さなことを感じた。
　先生は、しきりに、たいへんなことをいった。
「ああ、なんだ。」と、小さな声をあげた。
「先生、おたかえしてあの部屋へ、出て来ますよ。」と、先生は、大きな声で、先生の笑い声を出した。
```

1M 版と比べて、「と私は言った」「と、おじいさんが、いいました」のような会話文の地の文への戻りが安定し、
登場人物の名前（正吉、お里、大川）を出して同じ場面の中で使い回すようになった。意味の一貫性はまだ文の単位まで。

学習済みモデルは `checkpoints/ja10m/`（`params.bin` 42 MB）。
